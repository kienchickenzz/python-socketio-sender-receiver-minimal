TỔNG HỢP DATA STRUCTURES/DTOs TRONG TOÀN HỆ THỐNG


1. CONNECTION & REGISTRATION FLOW

---
1.1. CONNECTION_CONFIRMED (Server → Client)

Location: BaseConnectHandler (server) → All clients
{
  "client_sid": str  # Session ID của client
}
Used by: Sender, Receiver, Worker

---
1.2. RECEIVER_READY (Receiver → Server)

Location: ConnectionConfirmedHandler (receiver) → ReceiverReadyHandler (server)
{
  "session_id": str  # ID của receiver
}

---
1.3. WORKER_ACTIVE (Worker → Server)

Location: ConnectionConfirmedHandler (worker) → WorkerActiveHandler (server)
{
  "session_id": str  # ID của worker
}

---
1.4. SENDER_PAIR_REQUEST (Sender → Server)

Location: ConnectionConfirmedHandler (sender) → SenderPairRequestHandler (server)
{
  "session_id": str  # ID của sender
}



2. PAIRING FLOW

---
2.1. PAIR_REQUEST_SUCCESS (Server → Sender & Receiver)

Location: SenderPairRequestHandler (server) → PairRequestSuccessHandler (sender/receiver)
{
  "pair_id": str,        # UUID converted to string
  "sender_id": str,      # ID của sender
  "receiver_id": str     # ID của receiver
}

---
2.2. PAIR_REQUEST_FAILED (Server → Sender)

Location: SenderPairRequestHandler (server) → PairRequestFailedHandler (sender)
{
  "sender_id": str,         # ID của sender
  "reason": str            # Lý do thất bại (e.g., "No available receiver")
}


3. PROCESSING FLOW

---
3.1. REQUEST_PROCESSING (Sender → Server)

Location: PairRequestSuccessHandler (sender) → RequestProcessingHandler (server)
{
  "pair_id": str,           # UUID của pair
  "sender_id": str,         # ID của sender
  "receiver_id": str,       # ID của receiver
  "data": list[int]        # Dãy số cần xử lý (10 số ngẫu nhiên 1-20)
}

---
3.2. WORKER_JOB (Server → Worker)

Location: RequestProcessingHandler (server) → WorkerJobHandler (worker)
{
  "pair_id": str,           # UUID của pair
  "sender_id": str,         # ID của sender
  "receiver_id": str,       # ID của receiver
  "data": list[int]        # Dãy số cần xử lý
}

---
3.3. WORKER_RESULT (Worker → Server)

Location: WorkerJobHandler (worker) → WorkerResultHandler (server)
{
  "pair_id": str,              # UUID của pair
  "sender_id": str,            # ID của sender
  "receiver_id": str,          # ID của receiver
  "worker_id": str,            # ID của worker đã xử lý
  "original_data": list[int],  # Data gốc từ sender
  "result": list[int]          # Kết quả đã sort tăng dần
}

---
3.4. PROCESSING_RESULT (Server → Receiver)

Location: WorkerResultHandler (server) → ProcessingResultHandler (receiver)
{
  "pair_id": str,              # UUID của pair
  "sender_id": str,            # ID của sender
  "worker_id": str,            # ID của worker đã xử lý
  "original_data": list[int],  # Data gốc
  "result": list[int]          # Kết quả đã xử lý
}
